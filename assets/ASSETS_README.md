# 必要アセット一覧

コード側は各アセットが**存在しない場合でも自動でフォールバック描画**するため、
アセットを差し込まずにロジック確認・デバッグが可能です。
本番投入時は以下のファイル名・仕様に合わせて `assets/images/` `assets/audio/` に配置してください。

## 画像 (assets/images/)

| ファイル名 | 用途 | 推奨サイズ | 備考 |
|---|---|---|---|
| `bg_bunkasai.png` | 背景(文化祭風) | 960x540以上 | 横画面フル背景 |
| `yaga_kun_idle_0.png` | ヤガあげクン: 待機 | 300x300 | 羽ばたきアニメにする場合は `_0`〜`_n` を連番追加し、`player_component.dart` の読み込みロジックを配列対応に拡張 |
| `yaga_kun_aim_0.png` | ヤガあげクン: 狙い(真剣な表情) | 300x300 | |
| `yaga_kun_throw_0.png` | ヤガあげクン: 投球(全力羽ばたき) | 300x300 | |
| `yaga_kun_happy_0.png` | ヤガあげクン: 成功(喜ぶ) | 300x300 | |
| `yaga_kun_sad_0.png` | ヤガあげクン: 失敗(しょんぼり) | 300x300 | |
| `karaage.png` | 唐揚げ(投擲物) | 40x40 | 正方形、透過PNG |
| `cup.png` | 紙コップ | 120x160 | 上部が開口部(飲み口)になるデザイン |

> 既存のロゴ素材(鶏キャラクター)がある場合は、状態別に表情/ポーズ違いの
> バリエーションを作成のうえ上記命名規則でリネームしてください。

## 音声 (assets/audio/)

| ファイル名 | 用途 |
|---|---|
| `bgm_loop.mp3` | BGM(明るくポップ、ループ再生) |
| `sfx_click.mp3` | ボタンクリック音 |
| `sfx_charge.mp3` | ドラッグ中のチャージ音 |
| `sfx_throw.mp3` | 投球時「シュッ」 |
| `sfx_success.mp3` | 成功時「ポン!」 |
| `sfx_miss.mp3` | 失敗時の効果音 |
| `sfx_perfect.mp3` | Perfect時のファンファーレ(5投全成功でリザルト画面遷移時に自動再生) |

## フォント (任意)

丸みのあるポップな書体を使いたい場合は `assets/fonts/pop_font.ttf` を配置し、
`pubspec.yaml` のコメントアウトされた `fonts:` セクションを有効化してください。
